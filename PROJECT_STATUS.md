# PROJECT STATUS — THE BOYS MINECRAFT LAUNCHER

## Overview
**The Boys** is a next-generation Minecraft Java Edition launcher architected with a high-performance Rust + Tauri 2 backend and a modern React, TypeScript, and Tailwind CSS frontend.

## Release Readiness — Blocking
The native install/launch pipeline is implemented for Mojang version metadata and client files, Fabric/Quilt profiles, and Forge/NeoForge client installers. Mojang artifacts are SHA-1 checked, and launch arguments are built from the installed profile. It still requires a user-configured compatible Java runtime, depends on upstream loader/version availability, and has not been exercised end-to-end on clean installs across the full version/loader matrix. Treat installation and gameplay as **unverified** and do not call the launcher release-certified until those real-game tests pass.

## Completed Features

### 1. Dual Authentication Engine (Offline & Online)
- **Offline Mode**:
  - Deterministic player UUID calculation via standard UUID v3 formula: `MD5("OfflinePlayer:" + username)` with RFC 4122 variant & version 3 bits.
  - Custom skin selection: Steve (Classic 4px arm), Alex (Slim 3px arm), or custom texture URL.
  - Multi-profile offline saving, renaming, and one-click switching.
  - Distinct Offline badges and disclaimers explaining singleplayer / LAN server readiness without impersonating Mojang sessions.
- **Microsoft Online Authentication**:
  - OAuth 2.0 Device Code Authorization Flow (`https://login.microsoftonline.com/consumers/oauth2/v2.0/devicecode`).
  - Verification URI generation (`https://microsoft.com/link`) with user codes.
  - Entitlement verification layer and Java edition ownership check.
  - Profile retrieval displaying official Minecraft Java username, UUID, and skin renders.

### 2. Minecraft Version Management
- Official Mojang Version Manifest V2 synchronization (`https://piston-meta.mojang.com/mc/game/version_manifest_v2.json`).
- Categorized filtering: Releases, Snapshots, Betas, and Historical Alphas.
- Real-time version search and recommended Java runtime resolver (Java 21 for 1.20.5+, Java 17 for 1.18+, Java 8 for 1.16.5).
- Version selection plus native download and SHA-1 verification for client JARs, libraries, native archives, assets, and logging configuration.
- Play now verifies/installs missing version files before building the launch command.
- Java runtimes are not bundled or downloaded; a compatible Java executable must be configured.

### 3. Mod Loader & Modpack UI
- Instance metadata can record **Vanilla**, **Fabric**, **Forge**, **NeoForge**, or **Quilt**.
- Fabric and Quilt use their upstream profile metadata. Forge and NeoForge use their upstream installer JARs and generated version profiles.
- Loader support depends on upstream availability for the requested Minecraft version; the full matrix has not yet been validated.

### 4. Mod Discovery & Management (Modrinth & CurseForge)
- Live Modrinth API v2 integration (`https://api.modrinth.com/v2/search`) with filters for loaders, categories, and game versions.
- One-click mod installation directly into the selected instance's mods directory.
- In-instance mod manager: Enable / disable mods (`.jar` / `.jar.disabled`), local `.jar` file imports, dependency verification (e.g. Fabric API detection).

### 5. Graphics API Selection & System GPU Hardware Detection
- WebGL GPU query detecting actual hardware (NVIDIA GeForce, AMD Radeon, Intel Iris/Arc, Apple Silicon).
- Rendering backend selection:
  - **OpenGL**: Standard native LWJGL pipeline, 100% compatible.
  - **Vulkan**: Configured via VulkanMod integration, checks Vulkan 1.2+ driver support.
  - **DirectX 12**: Translation layer support via D3D12 / Zink wrappers.
  - **Automatic**: Hardware-adaptive selection.

### 6. Java & JVM Management
- RAM allocation sliders (Min/Max RAM in MB and GB).
- Garbage Collector selector: G1GC, Generational ZGC, Shenandoah, Parallel GC.
- Optimization presets: Balanced (Aikar's Flags), Ultra Low-Latency (ZGC), Lightweight.
- Custom JVM flags validator.

### 7. Metadata-Driven Game Installation & Launch
- The native installer resolves official Mojang version metadata and verifies client/library/native/asset files by SHA-1.
- It extracts native libraries safely, prepares legacy virtual assets, downloads logging configuration, and supports modern and legacy launch-argument metadata.
- Fabric/Quilt profiles are merged with Mojang version metadata; Forge/NeoForge profiles are generated by their upstream client installers.
- Java is started with the computed classpath and per-version arguments; an external compatible Java runtime is required.
- Automated unit tests cover path validation, loader-rule evaluation, metadata merging, argument substitution, and launch-argument assembly; real Minecraft gameplay remains unverified.

### 13. Older Hardware & Dedicated Resource Management
- **Potato PC Mode (Low-Spec Mode)**:
  - Toggles `.low-spec-mode` on the document root.
  - Eliminates backdrop blur filters, disables heavy box-shadows and animations, minimizing idle GPU fill-rate.
  - Special JVM preset capping RAM at 1.5GB–2GB with low-overhead Serial/G1GC flags (`-XX:+UseG1GC -XX:G1ReservePercent=15 -XX:MaxGCPauseMillis=40 -XX:+ExplicitGCInvokesConcurrent`).
- **Dedicated GPU Offload**:
  - Configures environment flags (`__NV_PRIME_RENDER_OFFLOAD=1`, `DRI_PRIME=1`) for dual-GPU laptops (Intel UHD + NVIDIA/AMD).
- **CPU Thread Affinity Selector**:
  - Allows capping launcher and game threads to 2 or 4 worker cores on older dual/quad-core processors to prevent OS freezes.

### 14. Full Rust / Tauri 2.0 Backend (`src-tauri/src/lib.rs`)
- Implemented production-ready Tauri invoke commands:
  - `get_system_hardware`: Queries `sysinfo` for OS version, RAM, CPU cores & model, disk space, and hardware class.
  - `install_minecraft_instance`: Downloads and verifies the selected Minecraft version, assets, libraries, natives, and supported loader profile.
  - `launch_game`: Builds launch arguments from installed metadata and starts Java with the instance game directory as its working directory.
  - `detect_java_installations`: Filesystem scanner inspecting system directories (`/usr/lib/jvm`, `C:\Program Files\Java`, etc.).
  - `fetch_ely_by_skin`: Queries Ely.by skinsystem for skins and cloaks.
  - `verify_file_hash`: SHA-1 and SHA-256 verification using `sha1` and `sha2` crates.
  - `save_skin_file`: Writes user-uploaded skin PNGs to local disk.
  - `ping_minecraft_server`: Checks server latency and online player status.

  - `.btn-tactile-amber`: Distinct tactile button for offline profile management.
- **Obsidian Panel Elevation (`.card-obsidian`)**:
  - Deep carbon `#080b11` backdrop with subtle grid patterning, gunmetal `#0e131d` cards, and hairline titanium borders.

## Architectural Decisions
1. **Hybrid Bridge Pattern**: The launcher operates directly in the browser with full offline profiles and live Mojang & Modrinth API calls, while also exposing full Tauri 2.x invoke commands when compiled to native desktop.
2. **Zero-Pill & Desktop Gaming UX**: Clean dark-first UI adhering to high-contrast WCAG AA standards, Outfit typography, JetBrains Mono tabular data, authentic tactile Minecraft buttons, and deep slate surfaces.
